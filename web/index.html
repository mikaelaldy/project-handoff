Model Context Protocol (MCP) Tools

Exposes standard stdio JSON-RPC tools for any compatible agent environment.

01

checkpoint

Stores session snapshot, runs client secret redaction, and embeds goal into CockroachDB vector table.

02

resume

Performs vector similarity lookup to fetch the single most relevant active handoff for the current prompt.

03

complete

Marks active handoff workstream resolved, archiving vector entry to prevent token overflow.
